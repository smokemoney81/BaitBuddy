## 🚨 KRITISCHE PROBLEME (Produktionsblockierung gering)

### 1. tar-Vulnerabilities in @capacitor/cli (BEKANNT)
- **Status:** Dokumentiert in CLAUDE.md
- **Beschreibung:** 13 CVEs in tar ≤7.5.20 (File Traversal, Symlink Poisoning, DoS)
- **Auswirkung:** Nur Android-Build betroffen (Capacitor-CLI), nicht Runtime
- **Lösung:** Capacitor Major-Version erhöhen (Breaking Change, zukünftig)
- **Aktion:** Keine — aktualisiert keine Anforderung für sofortige Fix

### 2. JSON.parse() ohne Fehlerbehandlung (20+ Stellen)
- **Status:** Teilweise bereits repariert
- **Überprüfung:** Code-Review zeigte viele JSON.parse bereits mit try-catch
- **Offender:** 
  - `src/components/location/LocationManager.jsx`
  - `src/services/NotificationService.js`
  - `src/lib/adConfig.js`
- **Priorität:** Medium (App-Stabilität)
- **Lösung:** Wrap in try-catch oder nutze Fehlerbehandlung

### 3. Ungeschützter ANON_KEY in `.env.production`
- **Status:** Technik OK, Best-Practice-Verletzung
- **Beschreibung:** VITE_SUPABASE_ANON_KEY hartcodiert
- **Auswirkung:** ANON_KEY ist öffentlich gedacht, aber Leck-Risiko bei git-Push
- **Lösung:** `.env.example` statt Production-Hardcoding
- **Priorität:** Hoch

### 4. localStorage/sessionStorage ohne Fehlerbehandlung (Private-Mode)
- **Überprüfung:** LocationManager.jsx, MiniKiBuddy.jsx, TripPlanner.jsx
- **Problem:** Keine try-catch bei `localStorage.setItem()` → App-Crash im Private-Browsing
- **Lösung:** `try { localStorage.setItem(...) } catch { /* Cache-Fehler OK */ }`
- **Priorität:** Mittel-Hoch

### 5. Premium-Plan-Fehlerbehandlung unvollständig
- **Status:** Code-Review: Fehlerbehandlung vorhanden aber "Best-effort"
- **Problem:** `grantReferralBasicReward()` loggt Fehler still, kein User-Feedback
- **Auswirkung:** Referral-Rewards könnten stumm scheitern
- **Lösung:** User-Alert bei Fehler hinzufügen
- **Priorität:** Kritisch (Geschäftslogik)
